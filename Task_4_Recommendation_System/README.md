# Recommendation System

A Python-based recommendation system that suggests books to users based on their interests and preferences.

The system uses **TF-IDF** and **Cosine Similarity** to compare book information and find relevant recommendations.

## Features

- Book recommendation
- Preference-based search
- TF-IDF text processing
- Cosine similarity
- Displays relevant book suggestions
- Saves recommendation results

## How It Works

1. The user enters a book or a preferred topic.
2. The system processes the available book information.
3. TF-IDF converts the text into numerical values.
4. Cosine similarity compares the user's preference with the books.
5. The system recommends the most relevant books.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity
